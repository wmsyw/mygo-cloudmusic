# Third-party code

`kuwo_des.go` ports the tables and rounds of UnblockNeteaseMusic server's
`src/kwDES.js` (<https://github.com/UnblockNeteaseMusic/server>), the
LGPL-3.0 implementation of Kuwo's query encryption. The port keeps the
same license: see `COPYING.LESSER` in this directory.

The rest of this package is written for this app and carries the
project's AGPL-3.0 license.
